# E-Commerce Sales Analysis

## Project Overview
This project analyses an e-commerce sales dataset using PostgreSQL and Power BI. The objective is to identify key sales trends, customer behaviour, product performance, and revenue patterns, and present the findings through an interactive Power BI dashboard.

## Tools Used
- PostgreSQL
- pgAdmin 4
- SQL
- Power BI

## Key Analysis
The SQL analysis covers:
- Overall business KPIs
- Revenue by product category
- Monthly revenue trends
- Top products by revenue
- Payment method analysis
- Customer analysis
- Revenue by country
- Repeat vs one-time customers
- Month-over-month revenue growth

## Dashboard KPIs
- **Total Revenue:** 1.64M
- **Total Orders:** 3,000
- **Total Customers:** 800
- **Average Order Value:** 547.50
- **Revenue per Customer:** 2.05K

## Key Insights
- Sports & Outdoors generated the highest revenue among product categories.
- Credit Card was the most frequently used payment method.
- Repeat customers significantly outnumber one-time customers.
- Monthly revenue shows noticeable fluctuations over time.
- The highest-performing products make a strong contribution to overall sales.
